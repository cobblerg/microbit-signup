# 📝 선착순 프로그램 참가 신청 웹 앱

이 프로젝트는 **Vercel**에 배포되어 빠른 속도와 세련된 UI를 제공하며, 신청 데이터는 **구글 스프레드시트**에 실시간으로 안전하게 저장됩니다.

---

## 🚀 빠른 시작 가이드 (3단계)

### 1단계: 구글 스프레드시트 준비하기
1. [구글 스프레드시트](https://sheets.new)를 새로 생성합니다.
2. 상단 메뉴에서 **[확장 프로그램] → [Apps Script]**를 클릭합니다.
3. 이 저장소의 `google-apps-script.js` 파일 내용을 전체 복사하여 붙여넣고 저장합니다.
4. 우측 상단 **[배포] → [새 배포]**를 클릭합니다:
   - 유형 선택(톱니바퀴): **웹 앱**
   - 다음 사용자로 실행: **나**
   - 액세스 권한: **모든 사용자 (Anyone)**
5. 배포 후 나오는 **웹 앱 URL**(`https://script.google.com/macros/s/.../exec`)을 복사합니다.

### 2단계: 웹사이트와 구글 시트 연결
1. `app.js` 파일을 열고, 맨 위 `GOOGLE_SCRIPT_URL`에 방금 복사한 URL을 붙여넣습니다.

### 3단계: Vercel 배포
1. [Vercel](https://vercel.com)에 로그인합니다.
2. **Add New... → Project**를 누르고 이 깃허브 저장소를 선택(Import)합니다.
3. **Deploy** 버튼을 누르면 나만의 고유 웹사이트 주소가 생성됩니다!
